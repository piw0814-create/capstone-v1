## 구현 중 수정 사항

React 개발 모드에서 토큰이 두 번 연속으로 화면에 출력되고 도구 호출 박스가 중복 표시되는 현상을 수정했다. 배열만 복사한 뒤 기존 메시지 객체와 도구 배열을 직접 수정하던 코드를, 새 메시지 객체와 새 도구 배열로 갱신하도록 변경했다.

Strict Mode와 백엔드 SSE 형식은 유지했다. 수정 후 실제 화면에서 중복 없는 답변과 도구 박스 1개를 확인했고, 같은 이전 상태로 상태 갱신 함수를 반복 실행해도 원본 상태가 변하지 않는 검사와 타입 검사도 통과했다.

## 캡처 및 관찰 방법

Chrome에서 F1부터 E2까지 실제 UI를 조작하고 캡처했다. F3와 F4는 빈 화면도 별도로 관찰한 후, 제출 캡처에는 후속 질문의 답변을 담았다. 토큰의 점진적 출력과 도구 상태 전환은 중간 화면을 연속 관찰하여 확인했다.

F5-back.png와 E2-back.png는 서버의 실제 표준 출력 로그에서 해당 시점의 INFO 행을 발췌한 텍스트 파일을 브라우저로 열어 캡처한 것이다. 터미널 앱 자체의 화면 캡처는 아니며, 로그 내용은 변경하지 않았다. F5는 입력 비활성화로 추가 전송을 할 수 없어 disconnect 취소 동작 자체는 검증하지 못했다.
